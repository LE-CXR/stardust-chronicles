# 复现与扩展用提示词

把下面整段交给另一个编程助手，可以在空目录里重建「星尘编年史」，或在现有仓库上继续做。不要放宽「不编造数据」这一条。

---

你要做的是一个中文静态网站，标题为「星尘编年史」。主题是元素周期表，但目标不是赛博朋克表格视频，而是能核对的科学交互。纯 HTML / CSS / JS，不要打包器，不要后端。用浏览器直接打开 `index.html` 必须能用；相对路径，适合 GitHub Pages 从仓库根目录发布。

## 体验

1. 开场用 Canvas 2D 粒子（不要为了 WebGL 去加构建步骤）。叙事顺序：星尘 → 大爆炸只留下氢、氦和极少的锂 → 恒星制造碳、氧，铁附近聚变不再净放能，更重的核靠中子俘获 → 人体按质量最多的是氧，然后是碳和氢（百分比只作为教材数量级，并写明不是体检值）→ 粒子落到周期表的格子上。可跳过。系统开启「减少动态效果」时直接进入表格。
2. 主界面是标准教材排法：主表第 6、7 周期把镧、锕放在第 3 族，铈–镥、钍–铹单独成行并对齐第 4–17 族。用一句话说明第 3 族归属仍有学术讨论。
3. 两种模式：「看故事」按章节高亮元素，仍允许点开其他格子；「自由探索」取消高亮。要能搜索符号、中文名、英文名。
4. 点任何 Z=1–118 的元素，打开档案：符号、中文名、英文名、原子序数、类别、周期与族、区块、物态、CIAAW 简约标准原子量、基态电子组态、按主量子数画的电子层（标明这不是轨道真实形状）、可见发射线、焰色、用途。手机约 390px 可用：表格可横滑，档案用底部面板。
5. 顶栏可以留一个「声音」按钮，明确写旁白和 BGM 还没做。不要假装有音频。

## 数据纪律

不准发明数值。

- 原子量只用 CIAAW 简约标准原子量。有区间的写出区间。CIAAW 没有标准原子量的，写「无标准原子量」，不要填最长寿同位素的质量数来冒充。
- 电子组态用通行基态，并校验各亚层电子数之和等于原子序数。Z ≥ 100 标成预测或计算。铹写 `[Rn] 5f14 7s2 7p1` 这一常见计算结论，不要改回过时的 6d1，除非你同时改掉说明。
- 可见谱线只来自 NIST Handbook of Basic Atomic Spectroscopic Data 的强线表（空气波长，埃换算成纳米）。每种元素最多约 8 条，保留钠 D 线这类强双线。手册没有的元素，谱线留空。色带颜色可以按波长做近似换算，但必须说明那不是拍摄的光谱。
- 焰色只写定性分析里反复出现的：锂、硼、钠、钾、钙、铜、铷、锶、铟、铯、钡、铊。色块是示意。说明钙、锶、钡、铜的肉眼颜色很大程度来自分子带。不要写实验步骤。
- 用途用你自己的中文，只写公开工业、医学、教材中的共识。超重元素写没有日用。
- 人体组成只在故事里给数量级：氧约 65%、碳约 18%、氢约 10%、氮约 3%、钙约 1.5%、磷约 1%，并声明不同教材会差一两个百分点。

中文元素名用现行大陆规范名。104–118 的正式汉字要能显示（字体需覆盖扩展 B 里的𨧀、𨭎、𨨏、𨭆，以及鐽 U+943D、鿬、鿫）。名字旁可加拼音，防止缺字。

## 建议文件

- `index.html`、`css/styles.css`、`js/intro.js`、`js/app.js`
- `data/elements.js` 供页面使用（全局变量，兼容 file://），`data/elements.json` 供检查
- `data/story.js`、`data/configs.json`、`data/spectra.json`
- `tools/build_elements.py` 生成页面数据，`tools/validate_elements.py` 检查 118 个元素、电子数、位置不碰撞、谱线落在 380–780 nm
- `fonts/` 放子集后的 Noto Sans SC / Noto Serif SC，并附 SIL OFL
- `README.md` 用中文写清本地打开和 GitHub Pages 步骤
- `.nojekyll`

视觉用深色天文台，而不是霓虹终端：黄铜色细线、按类别着色的左边线、面板像一份档案。类别色要能区分，但文字始终用浅色，不靠饱和底色辨认。

## 扩展时不要做的事

- 不要为了「每个元素都有谱线图」去编造波长。
- 不要把超重元素的理论物态写成已测量。
- 不要把焰色实验写成可操作步骤，尤其是铊、铍、汞。
- 不要引入必须 Node 构建才能打开的框架，除非同时保留一个无构建的静态入口。
